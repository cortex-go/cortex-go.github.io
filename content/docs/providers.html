Providers & API keys

The Settings dialog uses a provider dropdown instead of displaying a wall of credential fields. Choose a provider, store or replace its key, and Cortex keeps the credential in its private data directory.

v0.1 execution path

The first coding-agent path uses OpenCode Zen. Cortex already has credential slots for OpenRouter, OpenAI, Anthropic, Google AI and DeepSeek so provider/model selection can expand without redesigning settings.

Credential boundary

Keys are stored in a mode-0600 JSON file and are never returned by the settings API. Each OpenCode run receives an isolated temporary config/data directory and the selected credential through the child process environment.
