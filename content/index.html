01

Agent, not autocomplete

OpenCode provides the execution loop. Cortex gives it a workspace, visible tool activity, interruption, session copying and a clean browser interface.

02

Local or remote

The browser never has to be on the development machine. Keep Cortex on your workstation, NUC or VPS and work from wherever you are.

03

Small by design

A Go backend and focused web UI. Cortex is not trying to become an IDE universe; it is a control surface for coding agents.

FIRST VERSION

Born from dogfooding, not a diagram.

The first Cortex implementation extracts the coding-agent workflow proven inside Warden: DeepSeek V4 Flash through OpenCode Zen, streamed tool execution, recovery when headless OpenCode drops final output, workspace visibility, and explicit credential isolation.
