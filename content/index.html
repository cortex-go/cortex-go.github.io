01

Agent, not autocomplete

OpenCode provides the execution loop. Cortex gives it browser-selected workspaces, visible tool activity, interruption, session copying and a clean browser interface.

02

Local or remote

The browser never has to be on the development machine. Keep Cortex on your workstation, NUC or VPS and work from wherever you are.

03

Sessions, not an IDE

Open multiple agent sessions across different workspaces in browser tabs. Cortex deliberately leaves editing to the agent instead of rebuilding a conventional IDE around it.

FIRST VERSION

Born from dogfooding, not a diagram.

The first Cortex implementation extracts the coding-agent workflow proven inside Warden: DeepSeek V4 Flash through OpenCode Zen, streamed tool execution, recovery when headless OpenCode drops final output, browser workspace selection, multi-session tabs, and explicit credential isolation.
