Getting started

Build Cortex with Go, make sure opencode is available in the same environment, then start Cortex. By default its workspace root is your home directory; use --root when you want to confine it more tightly.

go test ./...
go build -o cortex ./cmd/cortex
./cortex
# optional tighter boundary:
./cortex --root ~/Repositories

Configure the first agent

Open Settings, choose OpenCode Zen, paste your API key, and save it. Cortex stores the key server-side and never sends it back to the browser.

Run a task

Open Cortex at 127.0.0.1:7331. A directory chooser opens automatically for a new session. Browse under the configured root and choose a workspace without typing a filesystem path. Describe the task, press Enter to run, and use Shift+Enter for a newline.

Work in parallel

Use the ＋ button to open another Cortex session. Each tab can use a different workspace and continue its own OpenCode conversation, so one browser window can supervise several independent development tasks.
