Getting started

Build Cortex with Go, make sure opencode is available in the same environment, then point Cortex at the parent directory containing the projects you want it to access.

go test ./...
go build -o cortex ./cmd/cortex
./cortex --root ~/Repositories

Configure the first agent

Open Settings, choose OpenCode Zen, paste your API key, and save it. Cortex stores the key server-side and never sends it back to the browser.

Run a task

Open Cortex at 127.0.0.1:7331, choose a workspace under the configured root, then describe the development task. Press Enter to run and Shift+Enter for a newline.
